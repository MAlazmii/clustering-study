# Source and data provenance

This is an independent new project, written from the squared-distance clustering
specification in `methods.md`. None of the older coursework algorithm source,
assignment documents, supplied datasets, notebooks, student submissions or recovered
cluster directories was imported. The existing Clustering-Algorithms repository
remains a separate historical coursework project, with its existing credits intact.

All study inputs are generated by this project's `generate` function. Component
labels are used only for evaluation and explanatory figures. The PNG/SVG figures
are plotted from the saved evidence, not drawn to imply hypothetical results.
No AI-service credentials, university login details, student identifiers or private
home paths are needed by the project. Commits use the owner's GitHub no-reply email.

MIT applies to this project's independent source, documentation and generated
figures/data. Dependencies and cited papers retain their own licenses. Citation
links are references, not included copies or assertions of ownership.
